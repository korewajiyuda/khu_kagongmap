💡 왜 API 키 입력칸이 있나요?
  • 안 넣어도 기본 추천 100% 작동: 키 없이도 내장된 제발요 추천 엔진이 거리·영업시간·콘센트 정보를 조합해 즉시 브리핑해 드려요.
  • 실제 Gemini AI 두뇌 연결: 키를 넣으면 실제 Gemini 2.5 Flash가 내 질문을 직접 분석해 매번 실시간 맞춤 답변을 작성해 줍니다. (공개 사이트에 제작자 키를 노출하면 구글 보안 정책상 자동 차단되어, 개인 브라우저에만 안전하게 저장해 쓰는 방식입니다.)
🚀 1분 무료 발급 & 사용 방법
  1. 1우측 위 [무료 API 키 발급받기 ↗]를 눌러 Google AI Studio에 로그인합니다.
  2. 2파란색 Create API key(API 키 만들기) 버튼을 눌러 AIzaSy...로 시작하는 키를 복사합니다. (무료 등급으로 과금 없이 사용 가능)
  3. 3아래 입력칸에 붙여넣고 [연동 저장]을 누르면 🟢 Gemini ON 불이 켜지며 실시간 AI 답변이 시작됩니다!
